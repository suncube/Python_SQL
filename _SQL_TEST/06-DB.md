# 3\*. Основы работы с итераторами и контейнерами

Реализуйте класс `SnakeMatrix` и отдельный класс-итератор `SnakeMatrixIterator`.

## 1. Конструктор класса `SnakeMatrix` должен поддерживать два способа создания объекта.

### Вариант 1. По размерности

Если в конструктор передаются два целых числа:

```python
matrix = SnakeMatrix(3, 4)
```

необходимо создать матрицу размером 3×4 и заполнить ее случайными целыми числами.
Диапазон случайных значений можно выбрать самостоятельно.

### Вариант 2. По готовым данным

Если в конструктор передается список списков:

```python
matrix = SnakeMatrix([
    [1, 2, 3],
    [4, 5, 6]
])
```

необходимо использовать переданную матрицу как внутреннее хранилище данных.
Размеры матрицы должны быть определены автоматически.

### Требования к конструктору

Конструктор должен корректно обрабатывать оба варианта:

```python
SnakeMatrix(rows, cols)
```

и

```python
SnakeMatrix(data)
```

При передаче некорректных аргументов необходимо выбрасывать исключение `ValueError`.

Также необходимо проверить, что:

- матрица не пустая;
- все строки имеют одинаковую длину;
- количество строк и столбцов больше нуля.

Индексация строк и столбцов начинается с **0**.

### Класс `SnakeMatrix` должен поддерживать доступ к элементам по двум индексам:

```python
matrix[i, j]
```

Например:

```python
matrix[2, 1]
```

Также необходимо реализовать:

```python
len(matrix)
```

Возвращает общее количество элементов матрицы.

```python
value in matrix
```

Проверяет наличие элемента в матрице.

### 2. Итератор

Необходимо реализовать отдельный класс `SnakeMatrixIterator`.

Класс `SnakeMatrix` должен возвращать объект этого класса из метода:

```python
__iter__()
```

Класс `SnakeMatrixIterator` должен реализовать метод:

```python
__next__()
```

который возвращает следующий элемент матрицы в соответствии с заданным порядком обхода.

Следующий код должен работать корректно:

```python
matrix = SnakeMatrix(data)

iterator = iter(matrix)

print(next(iterator))
print(next(iterator))
print(next(iterator))
```

---

### 3. Порядок обхода

Элементы матрицы должны возвращаться в порядке «змейки» по столбцам.

Для матрицы 6х6 итератор должен возвращать элементы в следующем порядке:

```text
00 10 20 30 40 50 51 41 31 21 11 01 02 12 22 32 42 52 53 43 33 23 13 03...
```

То есть:
- столбцы с четным индексом обходятся сверху вниз;
- столбцы с нечетным индексом обходятся снизу вверх.


### Ограничения

- Запрещено создавать новую матрицу или список элементов в требуемом порядке.
- Итератор должен вычислять следующий элемент во время выполнения `__next__()`.
- После обхода всех элементов метод `__next__()` обязан выбрасывать исключение: StopIteration
